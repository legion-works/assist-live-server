# Community rules

## Standards

- Respect each contributor.
- Discuss the work, not personal qualities.
- Do not use threats, harassment, sexual content, or personal attacks.
- Do not publish a contributor's private information.

## Scope and response

These rules apply to project discussions and public statements made for the project.
Maintainers can remove dangerous content and prevent participation.
Use a private maintainer contact to report unacceptable behavior.
Do not put private report data in public issues.
