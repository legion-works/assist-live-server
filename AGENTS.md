# Repository rules

- Keep the server and client in different packages.
- Keep model-runtime dependencies out of the client package.
- Do not give the server a Home Assistant administrator credential.
- Keep personal data, secrets, home names, private network addresses, and household recordings out of this repository.
- Use synthetic audio or audio with an applicable public license in tests.
- Use ASD-STE100 for documentation and comments.
- Keep the project marked experimental until an approved release is available.
- Get operator approval before publication.
- Run the commands in `CONTRIBUTING.md` before review.
